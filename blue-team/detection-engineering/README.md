# Detection engineering : concevoir des détections qui tiennent

**Domaine :** Blue team · **Niveau :** avancé · **Statut :** en préparation

Tout le cycle de la détection : modéliser une menace (MITRE ATT&CK), choisir
les bonnes sources, écrire des règles de qualité (Sigma, KQL, SPL), gérer les
faux positifs, mesurer la couverture, tester par émulation adverse et
industrialiser en detection-as-code.

Sources : MITRE ATT&CK, projet Sigma, documentation Splunk et Microsoft
Sentinel.
